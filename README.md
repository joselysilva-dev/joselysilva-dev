Sou estudante de **Engenharia de Software**, com foco em desenvolvimento **Backend e Full Stack**.

Minha formação combina programação, bancos de dados, segurança, cloud e desenvolvimento de interfaces. Transformo ideias e problemas reais em soluções digitais estruturadas — desde a organização dos dados e construção da API até a interface, documentação e publicação.

**Principais recursos**

- Landing page comercial responsiva
- Apresentação de planos, estrutura e profissionais
- Formulário digital de matrícula
- Área de login e ambiente do aluno
- Painel administrativo
- Blog com artigos e categorias
- Upload e gerenciamento de imagens
- Integração com WhatsApp
- SEO local e dados estruturados
- Progressive Web App
- Integração com API FastAPI

**Engenharia aplicada**

- Arquitetura baseada em componentes

- Comunicação frontend/API
- Estados de carregamento, sucesso e erro
- Semântica e acessibilidade
- Geração de sitemap e configuração de canonical
- Configuração por variáveis de ambiente

**Stack:** React 19, Vite 8, JavaScript, CSS, Python, FastAPI, SQLAlchemy e SQLite.
